# Архитектура и HTTP

Этап 4, 10.11.2026, код `90aac78`. Контракты восстановлены по обработчикам,
не являются обещанием публичного удалённого API. Сервер слушает loopback.
Пользовательские пути и последствия записи — [хранение](06-storage-and-exchange.md).

## ARCH-001 — путь действия

| Компонент                                                                         | Ответственность                                                                                   |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `app/js/app/main.js`                                                              | Загрузка, подключение обработчиков, подписки отрисовки, режим чтения, предложение локальной копии |
| `features/people,release,task.js`                                                 | Поля/проверки диалогов и изменение state                                                          |
| `core/render.js`, `core/plan.js`, `core/schedule.js`, `ui/board.js`               | Перерасчёт очереди, отрисовка команды/вкладок/доски                                               |
| `core/storage.js`                                                                 | State, разделение документов, dirty/сохранение/статус, исходные ревизии и аварийный кэш           |
| `core/split-storage.js`                                                           | HTTP-адаптер или localStorage с Web Locks/Web Crypto                                              |
| `core/storage-schema.js`, `storage-migration.js`                                  | Общая валидация, версии, канонический JSON, преобразование старых форматов                        |
| `features/data-io.js`, `features/release-transfer.js`, `core/release-transfer.js` | UI обмена, резервирование и чистые правила пакета релиза                                          |
| `server.js`, `lib/storage-api.cjs`                                                | Маршруты, статика, календарный proxy, копии, сигналы вкладок                                      |
| `lib/file-store.cjs`, `file-migration.cjs`, `installation.cjs`                    | Единственный файловый писатель, блокировки, атомарная запись, миграция и владение установкой      |
| BAT/VBS, `lib/launcher.cjs`                                                       | Поиск Node, вопрос/создание ярлыка, подготовка и скрытый запуск                                   |

Пример: открытая карточка → пользователь меняет длительность и применяет →
обработчик проверяет поля и меняет state → render перепаковывает очередь и
обновляет доску → save откладывает запись → адаптер отправляет изменённые
документы → сервер проверяет модель/ревизию и пишет → ответ обновляет ревизию
и индикатор. Отрисовка и успешное закрытие диалога предшествуют подтверждению записи.

## API-STORAGE-001 — три документа

Все маршруты ниже фактически реализованы; query отбрасывается при выборе
хранилища. JSON-ответы storage имеют `Cache-Control: no-store`.

| Маршрут                         | Метод и запрос              | Успех                                       | Побочные эффекты                                                                                |
| ------------------------------- | --------------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `/api/data`                     | GET                         | 200 `{data,revision}`; data может быть null | Чтение доски под lock                                                                           |
| `/api/preferences`              | GET                         | 200 `{data,revision}`                       | При отсутствии создаётся документ по умолчанию                                                  |
| `/api/system`                   | GET                         | 200 `{data,revision}`                       | При отсутствии создаётся документ по умолчанию                                                  |
| `/api/data`, `/api/preferences` | POST `{data,baseRevision}`  | 200 `{ok:true,data,revision}`               | Полная замена одного проверенного документа; для data предварительный auto-снимок по интервалу  |
| `/api/system`                   | POST `{patch,baseRevision}` | 200 `{ok:true,data,revision}`               | Частичный patch только calendar/queueNotice; launcher и migrations через этот маршрут запрещены |

`baseRevision` — строка SHA-256 канонического текущего документа (включая null
при отсутствии доски). Нельзя передавать произвольный номер версии вместо неё.
Ограничение тела — 5 МиБ. Другие методы: 405 и `Allow: GET, POST`.
Неверный JSON: 400; превышение: 413; схема: обычно 400
(`INVALID_DOCUMENT`, неподдерживаемая версия имеет свой код); конфликт: 409
`CONFLICT`; ожидание lock: 503 `STORAGE_LOCKED`; прочая I/O: 500.
Ошибки имеют `{ok:false,error,code}`. Клиент не переключается на localStorage
после неуспешной серверной записи.

## API-OTHER-001 — копии, календарь и жизнь вкладок

| Маршрут                   | Фактический метод / запрос                 | Успех                                                    | Ошибки и последствия                                                                                                                                                             |
| ------------------------- | ------------------------------------------ | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/api/backup`             | POST, сама доска JSON, без оболочки data   | 200 `{ok:true,name}`                                     | До 5 МиБ; 413 при превышении; миграция/проверка доски, запись отдельной копии с fsync и перечитыванием, ротация; catch: `status` либо 400, `{ok:false,error}`                    |
| `/api/backups`            | GET                                        | 200 `{backups:[{name,at,size,releases,tasks}]}`          | Числа могут быть null у нечитаемой копии; чтение списка не восстанавливает данные                                                                                                |
| `/api/restore`            | POST `{name,baseRevision}`                 | 200 `{ok:true,data,revision}`                            | До 5 МиБ; 413; неверное имя/нет файла/неверный JSON обычно 400; конфликт409; имя строго по шаблону, без разделителей; снимок before-restore и auto перед заменой, проверка доски |
| `/api/calendar?year=YYYY` | GET, год1900–2100                          | 200, plain text365/366 символов0/1/2                     | 400 неверный год;502 внешний источник/таймаут12с/неверная длина или символы; proxy isdayoff.ru с cc=ru и pre=1, без записи доски                                                 |
| `/api/health`             | Ограничение метода отсутствует; клиент GET | 200 `{ok:true,storageVersion:4,pid,dataFile,backupsDir}` | Проверяет идентичность установки и версию протокола; не подтверждает успешную запись пользовательских правок                                                                     |
| `/api/alive`              | Метод не ограничен; клиент POST `{tab}`    | 200 `{ok:true}`                                          | Непустая строка tab обновляет время и used; некорректное тело игнорируется                                                                                                       |
| `/api/bye`                | Метод не ограничен; клиент beacon `{tab}`  | 200 `{ok:true}`                                          | Удаляет tab и планирует проверку остановки; неверное тело игнорируется                                                                                                           |

У backup/restore ошибка отвечает JSON; 413 backup возвращается без явного
Content-Type. Список копий и health не обёрнуты общим storage catch:
нельзя обещать единый JSON-контракт при любой файловой ошибке этих маршрутов.
У alive/bye нет лимита тела и строгой схемы, сопоставимой со storage.

Любой путь с префиксом `/api/` отменяет текущий таймер остановки до обработки.
У неизвестного API нет отдельного общего JSON404: запрос доходит до раздачи
статики. Неподходящий метод backup/backups/restore/calendar также проходит
дальше, в отличие от строгого405 трёх storage-маршрутов.

## API-STATIC-001 — страница и ошибки адреса

`/` отдаёт `app/index.html`, остальные пути — только внутри `app/`, с
`Cache-Control: no-store` и типом по расширению. Query не является частью
имени файла. Ошибка decodeURIComponent даёт400 `Invalid URL`; выход за
проверяемую границу app —403 `forbidden`; ошибка чтения —404 `not found`.
Данные `data/`, `settings/`, `runtime/` не являются каталогами статики.
Метод для статической ветки явно не ограничен; каталог маршрутов не добавляет
не существующих PUT/DELETE или отдельного endpoint обновлений.

Основание: `server.js:http.createServer`, `lib/storage-api.cjs:createStorageApi`,
`lib/file-store.cjs`, `core/split-storage.js:createHttpStore`,
`features/data-io.js`, `features/calendar.js`, `core/keepalive.js`.
