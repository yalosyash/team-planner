# Справочник Team Planner

Справочник текущего поведения: как действия пользователя связаны с очередью,
доской и сохранением данных. Сейчас завершены **этапы 1–6**
[плана](../PRODUCT-DOCS-PLAN.md): состав продукта, словарь, модель, основные сценарии и проверки полей.
Правила и синтетические расчётные примеры подготовлены. Основной сквозной путь
проверен на изолированном приложении; это не полная приёмка всех функций.

Основание: commit `90aac7898f1665c4b54ba922dde03a7871ad1d4b`, проверка
10.11.2026. До подготовки документации рабочее дерево было чистым.
Первоначальный срез добавлял только документацию. Изменение от 10.11.2026
поверх 09dcf94 переводит окно сотрудников на применение по «Готово»;
сценарий, интерфейс, модель и матрица актуализированы.
Метод проверки — чтение реализации, разметки, стилей, запуска, тестов
и сопоставление документов. На этапах 1–2 тесты не запускались; на этапе 3 выполнены расчётные примеры,
calendar.mjs и task-labels.mjs.
На этапе 4 выполнены профильные проверки хранения и установки (протокол в матрице).
Рабочие данные, настройки и runtime не использовались.
На этапе 5 проверены интерфейс, сохранённые даты, полный обмен и конфликт
двух вкладок. [Протокол и непройденные проверки](../PRODUCT-DOCS-CHECKS.md)
отделены от инструкции. Текущие изменения окна сотрудников проверены обработчиками на синтетическом
DOM (tests/people-draft.mjs); прежний браузерный протокол их не подтверждает.
