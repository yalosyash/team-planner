## Окружение и изоляция

- Windows, Node.js v22.16.0, встроенный браузер Codex, окно около 910 × 900.
  Версия движка встроенного браузера не определялась; его не следует считать
  проверкой установленного Chrome, Firefox или мобильного Safari.
- Подготовка: [ui-fixture.cjs](product/checks/ui-fixture.cjs). Он копирует только
  `app/`, `lib/`, `server.js` в новый каталог `%TEMP%/planner-docs-ui-*`.
  Рабочие `data/`, `settings/`, `runtime/` не копируются и не читаются.
- Настоящий сервер из временной копии запускается с `--no-open --port=0`.
  HTTP-прокси для UI подменяет только ответ календаря синтетическим календарём
  пн–пт. Все маршруты хранения/копий работают с настоящим временным сервером.
  Настоящий isdayoff и его недоступность этой сессией не проверены.
- Приложение открывалось по уникальному loopback origin, без существующей
  пользовательской доски. `start.bat` рабочей установки не запускался.
- Тестовые вкладки и процесс фикстуры завершены; временные файлы оставлены
  для просмотра результата. Полный экспорт содержит только синтетические данные.

Запуск фикстуры:

```text
node --preserve-symlinks --preserve-symlinks-main docs/product/checks/ui-fixture.cjs
```

Она печатает root, origin реального сервера и ui прокси. Данные создаются через
интерфейс; завершение — Ctrl+C. Это средство воспроизведения, не тест с автоматическим
успешным результатом и не штатный запуск продукта.

## Что осталось непроверенным

- Полный CRUD людей/релизов/задач, палитра, drag-and-drop, смена исполнителя,
  статусы, FE/BE, ссылки, все способы закрытия каждого окна.
- Полный цикл передачи/возврата одного релиза, устаревшие пакеты, сопоставление
  людей и отмена во время резервирования через UI.
- Применение восстановления из списка через UI; в этой сессии проверен список,
  а серверные контракты восстановления проверялись на этапе4.
- Браузерный backend и миграция реального localStorage в установленном Chrome,
  read-only режим, мобильные размеры, другие браузеры.
- Сон/гибернация, аварийный выход, потеря питания, доставка beacon, все таймеры
  hidden-сервера, настоящий двойной щелчок BAT/VBS и ярлык на рабочем столе.
- Доступность и ответы внешних сервисов, все граничные и повреждённые файлы.

Этап5 дал проверенный сквозной срез и список границ достоверности. Он не
означает, что все пункты общего QA-плана прошли или все найденные проблемы
исправлены. Ожидаемое поведение переименования в справочнике согласовано
пользователем; подробности требуемого исправления хранятся только в TODO.
